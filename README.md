# Phase Simulator (PR-VLE + RK4 + 3D)

Интерактивный физический симулятор термодинамических состояний, фазовых равновесий и нестационарной динамики веществ. Проект объединяет строгое аналитическое ядро (уравнение Пенга — Робинсона), численный солвер Рунге — Кутты 4-го порядка (RK4) и 3D-визуализацию молекулярной динамики на WebGL.

## 🌟 Ключевые возможности

1. **Строгая термодинамика флюидов:**
   * Универсальное кубическое уравнение состояния Пенга — Робинсона (PR EOS).
   * Численный расчет фазового равновесия Жидкость — Пар (VLE) из условия равенства летучестей $\phi^L = \phi^V$.
   * Аналитический расчет спинодалей (границ метастабильности).
   * Расчет калорических свойств через функции отклонения (Departure Functions): Энтальпия $H$, Энтропия $S$, Теплоемкости $C_p, C_v$, внутренняя энергия $U$ и скорость звука $c$.

2. **Динамическая база данных элементов:**
   * Автоматическая загрузка параметров критических точек ($T_c, P_c, \omega$) и тройных точек из научной базы данных `chemicals` (IUPAC / DIPPR).
   * Поддержка аномальных веществ с отрицательным наклоном плавления (Галлий, Висмут, Сурьма, Кремний).

3. **Интегратор Рунге — Кутты 4-го порядка (RK4):**
   * Моделирование изобарных ($P = \text{const}$), изохорных ($V = \text{const}$) и адиабатических процессов во времени.
   * Воспроизведение температурных плато (скрытая теплота) при фазовых переходах 1-го рода (кипение, плавление).

4. **Интерактивная 3D-модель (WebGL Canvas):**
   * **Твердое тело:** кристаллический брусок с фононными тепловыми колебаниями решетки.
   * **Жидкость:** сплошной объем с бегущими 3D-волнами на мениске и поверхностным испарением пара.
   * **Газ:** газодинамическое расширение и броуновское движение тысяч мелких молекул по распределению Максвелла — Больцмана.
   * **Сверхкритический флюид:** непрерывная опалесцирующая среда с вихрями Тейлора — Грина без границы раздела фаз.
   * Полная синхронизация 3D-модели с таймлайном графиков 2D и анимация 60 FPS.

5. **Liquid Glass UI:**
   * Кастомный дизайн на базе Glassmorphism, мягкие анимации карточек и поддержка единиц измерения (Кельвины, °C, °F, МПа, атм, бар).

## 🚀 Запуск через GitHub Actions (без установки на ПК)

Вы можете запустить этот симулятор прямо в браузере с помощью **GitHub Codespaces** или **Streamlit Community Cloud**, не устанавливая Python и библиотеки локально.

### Вариант 1. Запуск в GitHub Codespaces (Рекомендуется)
1. Нажмите зеленую кнопку **`<> Code`** на главной странице репозитория.
2. Перейдите на вкладку **`Codespaces`** и нажмите **`Create codespace on main`**.
3. Дождитесь загрузки окружения (обычно 1-2 минуты).
4. В открывшемся терминале внизу экрана (в браузере) выполните:
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```
5. В правом нижнем углу появится уведомление `Your application is running on port 8501`. Нажмите **`Open in Browser`**, чтобы открыть симулятор.

### Вариант 2. Развертывание в Streamlit Community Cloud (Публичная ссылка)
Если вы хотите поделиться приложением с другими, вы можете развернуть его бесплатно:
1. Зарегистрируйтесь на [share.streamlit.io](https://share.streamlit.io) через свой GitHub.
2. Нажмите **`New app`**.
3. Выберите этот репозиторий, ветку `main` и укажите `app.py` в поле `Main file path`.
4. Нажмите **`Deploy!`**. Через пару минут ваше приложение будет доступно по публичной ссылке!

## 💻 Локальная установка и запуск

Если вы хотите запустить проект локально на своем компьютере:

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/denmat0xi/phase-simulator
   cd phase_simulator
   ```

2. **Создайте и активируйте виртуальное окружение:**
   * **Windows:**
     ```bash
     python -m venv .venv
     .\.venv\Scripts\activate
     ```
   * **Linux/macOS:**
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите симулятор:**
   ```bash
   streamlit run app.py
   ```

Сервер откроет новую вкладку в вашем браузере (по умолчанию `http://localhost:8501`).

## 📁 Архитектура проекта

* `data_provider.py` — Слой доступа к данным (DAL) и модели DTO. Загружает фундаментальные константы из библиотеки `chemicals`.
* `engine.py` — Термодинамическое ядро: кубическое уравнение Пенга — Робинсона, VLE-солвер (поиск равенства летучестей) и расчет функций отклонения (калорических свойств).
* `dynamics.py` — Модуль нестационарной динамики: интегрирование системы дифференциальных уравнений методом Рунге — Кутты 4-го порядка.
* `visualizer_3d.py` — Высокопроизводительный 3D-рендерер (HTML5 Canvas + WebGL) для симуляции теплового движения и фазовых переходов на микро-уровне (с интерполяцией между агрегатными состояниями).
* `app.py` — Слой представления (UI) на базе Streamlit: интерактивный дашборд с кастомным CSS (Glassmorphism), графиками Plotly и панелью управления анимацией.
